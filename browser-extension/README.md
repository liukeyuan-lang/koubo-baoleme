# 发送到口播爆了么

这是 Chrome / Edge Manifest V3 扩展。它只在用户点击扩展时读取当前打开的小红书单篇页面，发送前展示摘要，不读取 Cookie，也不自动翻页。视频会提取多个候选媒体源并按完整 MP4、页面 video 元素和资源类型排序；服务端在后台依次尝试，适合处理几分钟到约 20 分钟的长视频。

## 本地安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本文件夹。
4. 打开一篇小红书帖子，再点击扩展。
5. 默认服务地址为 `http://127.0.0.1:4173`。

## 部署配置

服务端设置：

```text
EXTENSION_IMPORT_TOKEN=一段足够长的随机字符串
```

在扩展“连接设置”中填写相同密钥。正式部署后，还需要把 `manifest.json` 的 `host_permissions` 增加为你的 HTTPS 产品域名，例如：

```json
"https://your-domain.example/*"
```

不要把真实导入密钥写进代码或提交到公开仓库。

## 当前边界

- 页面结构变化后可能需要更新选择器。
- 只发送当前已经加载的公开评论，最多 50 条。
- 不自动展开评论、不批量采集账号内容。
- 视频逐字稿由服务端后台转写；长视频会显示处理阶段和进度，单个源失败会自动尝试其他候选源，并在远程 URL 转写失败时尝试下载音轨后上传识别。
